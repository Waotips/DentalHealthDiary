# Дневник здоровья зубов

Android-приложение на Java для лабораторной работы №3 по теме «Медицинские приложения».

## Что делает приложение

- отмечает утреннюю и вечернюю чистку зубов;
- отмечает использование зубной нити или ирригатора;
- сохраняет уровень боли / чувствительности от 0 до 10;
- сохраняет текстовые заметки о состоянии зубов и десен;
- ведет историю записей в SharedPreferences;
- считает простой индекс ухода за день;
- показывает рекомендации по состоянию и отметкам;
- позволяет запланировать визит к стоматологу;
- отправляет push-уведомления о чистке зубов утром и вечером;
- отправляет уведомление о визите к стоматологу.

## Как открыть в Android Studio

1. Распакуйте архив.
2. В Android Studio выберите **File → Open**.
3. Откройте папку `DentalHealthDiary`.
4. Дождитесь Gradle Sync.
5. Запустите приложение на телефоне или эмуляторе.

## Как тестировать

1. Запустите приложение.
2. На Android 13+ разрешите отправку уведомлений.
3. Нажмите **Отметить утреннюю чистку**.
4. Нажмите **Отметить вечернюю чистку**.
5. Отметьте зубную нить / ирригатор.
6. Введите боль от 0 до 10 и заметку.
7. Нажмите **Сохранить самочувствие**.
8. Введите дату и время визита к стоматологу, например `2026-06-20` и `14:30`.
9. Нажмите **Сохранить визит и напоминание**.
10. Нажмите **Включить ежедневные напоминания**.

## Соответствие методичке

- Чистый и понятный UI: главная форма с ежедневными отметками, самочувствием, визитом и историей.
- Хранение данных: используется `SharedPreferences`.
- Фоновые задачи: используется `AlarmManager` и `BroadcastReceiver` для уведомлений.
- Предметная логика: рассчитывается индекс ухода и выводятся рекомендации по отметкам и уровню боли.

## Основные файлы

- `MainActivity.java` — логика приложения, хранение данных, расчет индекса, планирование уведомлений.
- `ReminderReceiver.java` — получение событий AlarmManager и показ уведомлений.
- `activity_main.xml` — интерфейс приложения.
- `AndroidManifest.xml` — разрешения и регистрация receiver.
